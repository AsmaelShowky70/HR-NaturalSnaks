## نبذة عن المشروع

تم تصميم النظام لشركة **Natural Snacks** لتجميع العمليات اليومية الخاصة بالعمالة والرواتب والعهدة في واجهة عربية واحدة. يحافظ التطبيق على البيانات تلقائيًا في متصفح المستخدم، ويتيح تصديرها واستعادتها عند الحاجة.

## المزايا الرئيسية

- كشف شهري للحضور والرواتب مع تسجيل 0 أو 0.5 أو 1 أو 2 أو 3 ورديات يوميًا.
- حساب تلقائي لإجمالي الورديات، الأجر، السلف، الجزاءات، المدفوع والمتبقي.
- تسجيل حضور يومي سريع بضغطة واحدة لكل عامل أو مجموعة.
- إدارة العمال والمقاولين والسيارات وأسعار الورديات والأرقام القومية.
- إنشاء شهور جديدة مع إمكانية نسخ قائمة العمال والأسعار من الشهر الحالي.
- إدارة العهدة النقدية: إيداعات، مصروفات، تصنيفات، فواتير ورصيد متبقٍ.
- لوحة مؤشرات تلخص العمالة والورديات والرواتب ورصيد العهدة.
- أرشيف للشهور مع إمكانية فتحها أو حذفها واستعادتها من سلة المهملات.
- تصدير كشف الحضور والرواتب إلى ملف Excel منسق وملون بصيغة XLSX.
- طباعة كشف رواتب مناسب للحفظ PDF، وطباعة كشف تسوية وتصفية العهدة.
- نسخ احتياطي واستعادة كامل البيانات بصيغة JSON.
- واجهة RTL عربية متجاوبة مع دليل استخدام تمهيدي.
- يعمل محليًا بدون اتصال بالإنترنت بعد تحميل الصفحة.

**[asmaelshowky70.github.io/HR-NaturalSnaks](https://asmaelshowky70.github.io/HR-NaturalSnaks/)**

يتم النشر تلقائيًا بواسطة GitHub Actions عند تحديث الفرع `main`.

## التشغيل محليًا

لا يحتاج المشروع إلى Node.js أو `npm` أو خادم backend.

1. نزّل المستودع أو انسخه:

   ```bash
   git clone https://github.com/AsmaelShowky70/HR-NaturalSnaks.git
   cd HR-NaturalSnaks
   ```

2. افتح ملف `index.html` في متصفح حديث.

   ولأفضل تجربة أثناء التطوير يمكن تشغيل خادم ملفات ثابت، مثل إضافة Live Server في VS Code، ثم فتح العنوان الذي يعرضه الخادم.

## طريقة الاستخدام المختصرة

1. افتح تبويب **كشف الحضور والرواتب** وسجل عدد الورديات لكل يوم.
2. استخدم **تسجيل الحضور السريع** لإدخال حضور يوم محدد بسرعة.
3. أضف العمال والمقاولين من **سجل العمال والمقاولين**.
4. سجل الإيداعات والمصروفات من **إدارة العهدة والمصروفات**.
5. راجع النتائج من **لوحة المؤشرات**.
6. صدّر ملف Excel أو اطبع التقرير المالي عند نهاية الشهر.
7. نزّل نسخة JSON احتياطية بانتظام من تبويب **النسخ الاحتياطي**.

## التخزين والخصوصية

- البيانات لا تُرسل إلى خادم؛ يتم حفظها في `localStorage` داخل المتصفح والجهاز المستخدم.
- بيانات كل متصفح وجهاز مستقلة عن الأجهزة الأخرى.
- مسح بيانات الموقع أو تغيير المتصفح قد يؤدي إلى فقدان البيانات المحلية.
- استخدم زر النسخ الاحتياطي واحفظ ملف JSON في مكان آمن قبل تغيير الجهاز أو تنظيف بيانات المتصفح.
- GitHub Pages ينشر ملفات التطبيق فقط، ولا يملك وصولًا إلى بيانات التشغيل المحلية.

> هذا المشروع مناسب كأداة محلية أو داخل فريق صغير على جهاز محدد. لا يحتوي حاليًا على حسابات مستخدمين أو صلاحيات أو قاعدة بيانات مشتركة بين الأجهزة.

## التقنيات المستخدمة

- HTML5 وCSS3.
- JavaScript Vanilla بدون framework.
- `localStorage` للتخزين المحلي.
- [ExcelJS](https://github.com/exceljs/exceljs) لإنشاء ملفات XLSX منسقة.
- [SheetJS / XLSX](https://github.com/SheetJS/sheetjs) كمسار بديل للتصدير.
- GitHub Actions وGitHub Pages للنشر.

## النشر على GitHub Pages

ملف `deploy-pages.yml` يرفع محتوى المستودع كما هو إلى GitHub Pages عند كل push إلى `main`.

لأول مرة فقط، من إعدادات المستودع:

1. افتح **Settings → Actions → General** وتأكد من السماح بتشغيل GitHub Actions.
2. افتح **Settings → Pages**.
3. اختر **GitHub Actions** كمصدر النشر، إذا لم يتم اختياره تلقائيًا.
4. انتظر انتهاء Workflow باسم **Deploy to GitHub Pages**.
